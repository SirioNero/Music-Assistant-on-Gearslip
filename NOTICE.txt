Music Assistant for Xonos: package 2.10.8-3 for x86_64

Xonos downloads this package only when you tap "Make Xonos your Music Assistant server". It is built
from source by the workflows of https://github.com/SirioNero/Music-Assistant-on-Gearslip (folder server/,
with the exact versions and the build scripts). Its parts, their licenses and their sources:

Xonos's own files: bin/python3, app/xonos_server.py, app/av, app/modern_colorthief.py,
app/music_assistant_frontend, and the orjson and aiodns stand-ins in site-packages (+xonos)
    License: AGPL-3.0-or-later (licenses/Xonos-AGPL-3.0.txt)
    Source: https://github.com/SirioNero/Music-Assistant-on-Gearslip

Music Assistant 2.10.8 (app/music_assistant), changed for the phone by server/ma/prepare.py
    License: Apache-2.0 (licenses/Apache-2.0.txt)
    Source: https://github.com/music-assistant/server/tree/2.10.8

Python 3.13 for Android (lib/libpython3*.so, lib/python313.zip, lib/python3.13/lib-dynload),
as built by Chaquopy 17.2.0. Python's standard library includes other software (expat, libffi,
libmpdec, HACL*, bzip2, xz, zlib...): https://docs.python.org/3.13/license.html
    License: PSF-2.0 (licenses/Python.txt); Chaquopy: MIT (licenses/Chaquopy.txt)
    Source: https://github.com/chaquo/chaquopy/tree/17.2.0, https://www.python.org/downloads/source/

OpenSSL 3, for Python and the Python packages (lib/libssl_*.so, lib/libcrypto_*.so)
    License: Apache-2.0 (licenses/Apache-2.0.txt)
    Source: https://github.com/openssl/openssl, as built by Chaquopy

SQLite, for Python (lib/libsqlite3_*.so)
    License: public domain
    Source: https://sqlite.org/src, as built by Chaquopy

FFmpeg 7.1.5 (bin/ffmpeg, bin/ffprobe, lib/libav*.so, lib/libsw*.so), built by server/ffmpeg/build.sh
with --enable-version3, without GPL parts
    License: LGPL-3.0-or-later (licenses/LGPL-3.0.txt and licenses/GPL-3.0.txt)
    Source: https://ffmpeg.org/releases/ffmpeg-7.1.5.tar.xz

Mbed TLS 3.6.5, inside FFmpeg for https
    License: Apache-2.0 or GPL-2.0-or-later (licenses/Mbed-TLS.txt)
    Source: https://github.com/Mbed-TLS/mbedtls/releases/tag/mbedtls-3.6.5

    License: Apache-2.0 WITH LLVM-exception (licenses/Apache-2.0.txt)
